## Preparation

Follow README for Ollama or explicit OpenAI configuration; build evidence index.
Run tests/Ruff and startup smoke. Rehearse actual configured model before event.

local Ollama avoids hosted generation. No offline fallback exists.

## Five-minute sequence

1. Minute 1: choose synthetic example or enter unfamiliar enquiry. Show extracted
   customer facts, literal quotations, unknowns and active provider/model.
2. Minute 2: inspect provisional candidates and evidence source/page/excerpt. Explain
   source demonstration scope and visible limitations; do not promise fixed rankings.
3. Minute 3: change consequential fact through expert review, then apply. Show new
   retrieval/assessment and retained original text. Pending edits hide stale export.
4. Minute 4: inspect customer-defined or TBD criteria, independent reference assays,
   representative states and held-out runs. Show warnings and unchecked claims.
5. Minute 5: enter incomplete enquiry and show appropriate abstention/questions.
   Download Markdown and JSON; changed input hides stale output.

## Recovery

- Empty input: enter enquiry or choose example.
- Missing model/configuration/index: show actionable error, repair prerequisite and
  retry. Do not substitute baseline recommendations.
- Insufficient evidence: explain abstention and needed evidence/expert review.
- UI failure: evaluation runner can generate same pipeline outputs with configured
  provider; previously saved outputs must be labeled with their run provenance.
- Scientific concern: withhold claim and request expert review. Passing schema and
  citation checks cannot resolve scientific disagreement.
