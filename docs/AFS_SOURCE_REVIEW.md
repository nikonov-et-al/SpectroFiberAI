## Review boundary

Citation/page coverage and missing-page checks can be automated. A text-only pipeline can flag absent citations, weak page coverage, and unsupported configuration fields, but cannot reliably decide whether a slide image or a scientific claim supports a recommendation. D01–D08 can receive an algorithmic source-coverage pass; defensibility of the actual spectroscopy recommendation, exact setup, and experimental acceptance criteria still needs an expert. D08 additionally needs S04 review before claims based on that study are accepted.
